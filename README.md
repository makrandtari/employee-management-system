# Employee Management System

A web-based Employee Management System developed using Ruby on Rails.

## Features

- Create Employee
- View Employee List
- Show Employee Details
- Update Employee
- Delete Employee
- Employee Validations
- Employee Profile Image Upload

## Technologies Used

- Ruby
- Ruby on Rails
- SQLite3
- HTML
- CSS
- ERB

## Rails Concepts Used

- MVC Architecture
- CRUD Operations
- RESTful Routes
- Active Record
- Strong Parameters
- Model Validations
- Active Storage

## Installation

1. Clone the repository

   git clone YOUR_REPOSITORY_URL

2. Go to project directory

   cd employee_managment_system

3. Install dependencies

   bundle install

4. Create database

   rails db:create

5. Run migrations

   rails db:migrate

6. Start Rails server

   rails server

7. Open browser

   http://localhost:3000
